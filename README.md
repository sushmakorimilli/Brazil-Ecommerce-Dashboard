# Brazil E-Commerce Sales Dashboard
## Overview
Developed an interactive Power BI dashboard to analyze Brazil e-commerce sales performance, customer behavior, order trends, and revenue insights.

## Tools Used
- Power BI
- SQL
- Excel
- Power Query
- DAX

## Dashboard Features
- Sales trend analysis
- KPI tracking
- Revenue analysis
- Customer segmentation
- Top-performing products analysis
- Delivery performance analysis

## Data Processing
- Performed data cleaning and transformation using Power Query and Excel.
- Created data models and relationships across multiple datasets.
- Utilized SQL queries for data extraction and analysis.
## Outcome
Generated actionable business insights through interactive visualizations and data-driven analysis.
